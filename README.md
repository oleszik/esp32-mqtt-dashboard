# ESP32 MQTT Dashboard

## Goal
Build an end-to-end IoT system where an ESP32 publishes sensor data over MQTT and a containerized Linux backend stores and visualizes it.

## Planned features
- ESP32 sensor node with Wi-Fi/MQTT
- Mosquitto broker
- Python subscriber/service
- Persistent data storage and web dashboard
- Device online/offline state and reconnection handling
- Docker Compose deployment
- Documented MQTT topics/payloads

## Portfolio objective
Demonstrate ESP32/C++, MQTT, IoT architecture, Python, Docker, Linux, networking and end-to-end integration.

## Status
Planning / initial development.
